## 👩‍💻 Troubleshooting
If you encounter issues while using the ESP32 ULP Temp Sensor, consider the following tips:

- **Connection Problems:** Ensure the USB cable is securely connected to both the computer and the ESP32.

- **No Data Displayed:** Make sure that the ESP32 is powered on and the values are being printed to the serial monitor.
